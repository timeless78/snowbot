## 개발 환경 (인계 자료와 다름)

- **Android API 28 이상**(인계 자료는 26+), Gradle 8.0 이상, Java 또는 Kotlin.
- 공모전 페이지가 소개하는 Pleos Connect SDK: **Vehicle**(차량 상태), **FusedLocation**(위치), **NaviHelper**(길 안내 연동), **TextToSpeech · SpeechToText**(음성 입출력).
  인계 자료의 "Gleo AI SDK(STT·TTS·**LLM**)"는 이 목록에 **LLM 이 없다**. LLM 을 쓸 수 있는지는 Pleos 개발 문서에서 확인해야 한다.
- 에뮬레이터로 구동 검증 가능. 예시: 음성 메모 앱(STT), 안전운전 점수 앱(Vehicle), 배달 기사용 앱(NaviHelper).

## 권리·유의사항 (요약)

- 순수 창작물, 타 공모전 수상작 불가. 제3자 권리 침해 책임은 응모자.
- 출품 자료 지식재산권은 응모자. **수상작은 주최 측이 통상실시권, 결과 발표 후 4개월 우선협상권을 가질 수 있다**(조건은 협의).
- 상금은 대표자에게 일괄 지급, 제세공과금 원천징수.
- 현대자동차그룹 임직원은 참가 가능하나 수상 제외.

## 우리 계획에 미치는 영향

1. **하드웨어(SnowBot) 동반 출품 허용 여부는 요강에 없다.** 심사 대상은 앱(APK)이고, PT 시연은 "에뮬레이터 화면 또는 기기". 외부 모듈을 금지하는 말도 없다.
   → 앱이 **모듈 없이도 동작**(가상 SnowBot)하게 하는 기존 방향이 맞다. SnowBot 실물은 PT 에서 "보조 시연"으로 쓸 수 있는지 **설명회(10/28)에서 묻거나 이메일 문의**한다 (아래 초안).
2. **가산점을 노린다.** 마감 전에 에뮬레이터에서 도는 최소 앱(가상 SnowBot + 스킬 1개) + 시연 영상 + GitHub(APK)를 내면 가산점. 20일 안에 가능한 범위로.
3. **사업성 숫자가 필요하다.** 타깃 고객, 예상 MAU, Retention Rate, 확대 계획을 기획서 6번에 써야 한다.
4. **LLM 사용 가능 여부 확인.** 공모전이 소개한 SDK 에는 STT·TTS 만 있다. 대화형 기능은 외부 LLM API(서버 경유) 또는 규칙 기반으로 설계해야 할 수 있다.
5. **숏폼은 SnowBot 의 강점.** 움직이는 눈사람 로봇은 세로 영상에 잘 맞는다. 본상과 별도로 도전할 만하다(가산점은 없음).
6. 12/3~4 서울 오프라인 PT, 2027-02 행사 현장 참석이 필요하다(선정 시).
