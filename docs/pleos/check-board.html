적용

스노봇 대화를 Pleos 음성으로 바꿨습니다

2026-11-02

바뀐 흐름

  • 듣기: [스노봇과 말하기]를 누르면 차의 Pleos 듣기 엔진이 차 마이크로 듣고 글자로 바꿉니다. 서버에는 소리 대신 다 들은 글자만 갑니다.
  • 이름 고치기: 엔진이 "스노프"로 알아들으면 앱이 "스노봇"으로 고쳐서 보냅니다.
  • 말하기: 차 스피커로 나갈 대답은 서버가 글자로 보내고, Pleos 목소리 엔진이 문장 차례로 읽습니다. 기본 화자는 seoyoon 입니다.
  • 바뀌지 않은 것: 스노봇 몸체 스피커로 내는 말은 몸체가 Pleos 밖이라 지금처럼 서버 목소리(Suzu)입니다. Pleos 엔진을 못 쓰는 기기에서는 예전 방식으로 돌아갑니다.

에뮬레이터에서 확인한 것

  • 글자로 "스노프, 오늘 기분 어때?"를 넣으면 화면에 "나: 스노봇, 오늘 기분 어때?"로 나오고, 대답 두 문장을 Pleos 목소리로 차례로 끝까지 읽었습니다.
  • [스노봇과 말하기]를 누르면 Pleos 서비스가 차 마이크를 열었습니다. 말없이 다시 누르면 "미안해요, 잘 못 들었어요."를 Pleos 목소리로 답했습니다.
  • 서버 시험 23개 통과(새 방식 3개 추가). 새 서버는 배포했고, 예전 앱도 그대로 동작합니다.
  • 남은 것: 사람이 실제로 말해서 알아듣는지, 목소리가 스노봇에 어울리는지는 직접 들어 봐야 합니다(위 확인 현황).
시험 기록

Pleos TTS·STT 를 에뮬레이터에서 써 봤습니다

2026-11-02

결론: 차 안 엔진(ON_DEVICE)으로 말하기·알아듣기 둘 다 됩니다

설명회에서 들은 대로 앱 설정 파일에 권한 두 줄(pleos.car.permission.TTS_SERVICE, STT_SERVICE)만 적었더니 승인 없이 바로 됐습니다. 에뮬레이터의 Pleos 음성 서비스는 4.2.10 판이고, 두 권한 모두 따로 허락받을 필요가 없는 등급(normal)입니다.

0.10초TTS: 말하라고 한 뒤 소리가 나기 시작할 때까지
21문장 중 20STT: 이름 "스노봇"을 빼면 맞게 알아들은 문장
약 0.4초STT: 말이 끝난 뒤 최종 글자가 나올 때까지

어떻게 시험했나

  • 앱에 시험 화면(SpeechCheckActivity)을 만들었습니다. 개발용(debug) 빌드에만 들어가고 제출용 APK 에는 들어가지 않습니다.
  • TTS: "안녕하세요. 저는 스노봇이에요. 오늘도 안전 운전하세요."를 읽게 했습니다. 재생 시작, 끝, 소리 크기(RMS) 신호가 모두 들어왔고 4.8초 동안 읽었습니다.
  • STT: Mac 의 한국어 음성(유나)으로 문장 7개를 녹음 파일로 만들어 넣었습니다. 같은 문장을 보통 속도, 빠르게, 차 소음(낮은 웅웅 소리)을 섞어서 각각 넣어 모두 21번 시험했습니다. SDK 가 녹음 파일을 직접 받는 기능(sendAudio)을 써서 사람이 말하지 않아도 시험할 수 있었습니다.
  • 마이크로 직접 말하는 시험은 아직 안 했습니다. 확인 현황의 "마이크로 말해서 인식" 항목을 보세요.

시험하다 새로 알게 된 것

  • 에뮬레이터의 Pleos 음성 서비스에는 pleos.car.permission.LLM_SERVICE 라는 권한도 있습니다. 차 안 언어 모델(AI 대화) 기능으로 보이지만, 공개된 SDK 나 문서는 없습니다. 설명회에서 "아직 공개되지 않은 SDK 도 줄 예정"이라고 한 것과 관련이 있을 수 있어서 공지를 지켜보겠습니다.
  • STT SDK 안에는 특정 단어를 더 잘 알아듣게 하는 설정(LMBoostConfig)도 있지만 문서에 없는 기능이라 쓰지 않았습니다.
  • 이 에뮬레이터는 앱을 사용자 10번 계정에서 돌립니다. 시험 파일을 넣을 때 이 점을 맞춰야 했습니다.

좋은 소식

차 음성 기능(TTS·STT)을 바로 쓸 수 있다 32:29 38:17

TTS는 글자를 소리로 읽어 주는 기능, STT는 사람 말을 글자로 바꾸는 기능입니다.

공모전 기간에는 앱 설정 파일에 권한을 적기만 하면 승인 없이 쓸 수 있다고 했습니다. 위치 기능(FusedLocation)도 같습니다. 모의 심사에서 점수가 가장 낮았던 기술 활용성(25점 중 14.3점)의 이유가 "듣기·말하기를 외부 API 가 맡는다"였으니, 이것으로 바로 답할 수 있습니다. 11/2 시험으로 실제로 되는 것을 확인했습니다(위 시험 기록).
