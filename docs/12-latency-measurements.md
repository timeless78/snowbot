## 재는 방법

- **도구:** `server/tools/sim.py talk` — 맥 스튜디오(유선)에서 클라우드 서버(NAVER Cloud, wss)로 붙어 차량 앱과 같은 메시지를 보낸다.
- **입력:** 미리 만든 질문 음성 WAV 4개(합성 음성, 16kHz) — "안녕, 스노봇. 오늘 기분 어때?" · "차 안 공기 괜찮아?" · "나 좀 졸린 것 같아." · 힘든 일 이야기 한 문장.
- **말 끝:** 마지막 소리 조각을 보내고 `listen_end` 를 보낸 순간.
- **첫 소리:** 서버가 보낸 목소리(PCM) 첫 조각이 도착한 순간.
- **글자 확정:** 확정 `heard`(final) 메시지가 도착한 순간.
- **에뮬레이터 앱으로 잰 값이 아니다.** 맥 스튜디오에 마이크가 없어 에뮬레이터 듣기는 디버그 명령(`--es chat`)으로 시험했다. 에뮬레이터 앱으로 다시 재면 이 문서에 표를 더한다.
- 서버 설정: Scribe v2 Realtime → Claude Haiku 5.5(생각 끔, effort low, 스트리밍, 문장 단위) → ElevenLabs v4 Turbo(Suzu).
