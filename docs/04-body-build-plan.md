# 외형 제작 준비 (2026-10-26)

C 공업 디자인(`02-design-options.md`)을 실제 출력물로 만드는 순서. 3D 프린터가 없으므로 **출력 대행**을 기준으로 한다.
부품은 2026-11-07 도착 예정(`03-parts-list.md`). 치수 중 "자료값"은 판매 페이지·일반 규격 값이라 실물로 다시 잰다.

## 전체 순서

```mermaid
flowchart LR
  A["지금: 공구·설계 도구 준비<br/>자료값으로 1차 모델"] --> B["11/7 부품 도착<br/>캘리퍼스로 치수 재기"]
  B --> C["모델 고치기<br/>(눈 주변부터)"]
  C --> D["시험 출력<br/>공차 조각 + 눈 기구"]
  D --> E["본 출력<br/>머리·몸통·목"]
  E --> F["조립·배선"]
  D -->|"안 맞으면"| C
```

출력 대행은 한 번에 1~2주 걸린다(업체 안내 6~9영업일 등). **시험 출력 1번 + 본 출력 1번**을 목표로, 시험 출력에 어려운 부분을 몰아넣는다.

## 1. 지금 할 일 (부품 오기 전)

### 1-1. 공구

| 공구 | 왜 필요한가 | 필수 |
|---|---|---|
| **디지털 캘리퍼스** (0.1mm 까지 재는 자) | 서보·보드·카메라의 실제 크기를 재야 설계가 맞는다. 판매 페이지 치수는 판매자마다 다르다 | **필수** |
| **납땜인두** | 핀 헤더 납땜, M2 인서트를 출력물에 녹여 박기 | **필수** |
| M2 육각 렌치 (버튼머리 M2 는 보통 1.3mm) | 머리 앞뒤를 잇는 육각 나사. 산 나사 세트에 렌치가 들었는지 도착 후 확인 | 필수 |
| 니퍼, 사포(400·800방), 작은 줄 | 출력물 지지대 자국 정리, 구멍 다듬기 | 있으면 좋음 |
| 순간접착제 | 코·눈 링 붙이기 | 있으면 좋음 |

### 1-3. 설계 도구 정하기

| 방법 | 하는 일 | 장점 | 단점 |
|---|---|---|---|
| **A. 코드로 설계 (추천)** — Python 3D 설계 라이브러리(build123d 등) | Claude 가 치수를 숫자로 적은 설계 코드를 쓰고, 실행하면 출력용 파일(STL)과 미리보기 그림이 나온다 | 실물을 재서 숫자만 바꾸면 전체가 다시 만들어진다. 사용자가 3D 프로그램을 배우지 않아도 된다 | 둥근 곡면 다듬기는 손으로 그리는 프로그램보다 어렵다. 미리보기를 그림으로 확인하며 고친다 |
| B. 직접 그리기 — Fusion(개인 무료), Onshape(무료, 공개 문서) | 사용자가 마우스로 그린다 | 보면서 바로 고친다 | 프로그램을 배워야 한다. 12월 시연까지 시간이 빠듯하다 |

**결정 (2026-10-26, 사용자): A 코드로 설계한다.** `cad/` 폴더에 환경을 설치했고 1차 배치 모델을 만들었다 → [../cad/README.md](../cad/README.md)

공구 현황 (사용자): 납땜인두·육각 렌치·사포 있음. 피아노선은 없음(2026-11-07 확인) — 눈꺼풀 막대는 클립(약 0.8~1mm)으로 먼저 시험하고 1mm 피아노선 또는 1mm 황동선을 따로 산다. **2026-10-29 네이버 쇼핑 구매:** 블루텍 디지털 캘리퍼스 BD500-150(스테인리스 150mm), PLATO 170 플러시 커터, 황동 정원봉 2mm × 1m (HK재료, 쓸 길이로 쇠톱으로 잘라 씀). 합계 41,800원(배송비 포함).

출력 업체에 보내는 것은 종이 설계도가 아니라 **조각별 STL 파일 + 주문표(조각·색·개수·메모)** 다. 업체는 시험 출력 주문 전(11/10쯤)까지 정하면 되고, 업체별 차이(출력 방식·색·권장 틈)는 설계 코드의 숫자로 맞춘다.

## 3. 출력 조각 목록 (C 기준)

| 조각 | 색 | 메모 |
|---|---|---|
| 얼굴판 (머리 앞) | 흰색 | 눈 구멍 2, 코 끼우는 구멍, 눈썹 축 구멍. 앞판을 떼면 눈 기구를 고칠 수 있게 |
| 뒤 덮개 (머리 뒤) | 흰색 (반투명은 아직 미정) | 환기 슬롯, 마이크 구멍, 육각 나사 자리 |
| 눈 흰자 돔 × 2 | 흰색 | 한쪽 검은자 가운데에 카메라 렌즈 |
| 검은자 링 × 2 | 짙은 회색 | 카메라 눈과 장식 눈을 같은 모양으로 |
| 눈꺼풀 × 2 + 연결부 | 흰색 | 서보 1개로 두 눈꺼풀을 같이 움직임 |
| 눈썹 × 2 + 축 캡 | 짙은 회색 (검은 고무 막대로 바꿀 수 있음) | 서보 1개, 가운데 세로 슬라이더로 두 눈썹을 같이 돌림 |
| 코 | 주황 | 약 1cm, 가로 홈. 끼우는 방식 (길이를 바꿔 보기 쉽게) |
| 머리 안 틀 | 아무 색 | 보드·눈꺼풀 서보·눈썹 서보·끄덕임 서보 고정 |
| 목 회전판 + 끄덕임 브래킷 | 짙은 회색 | 베어링 자리, 서보 혼 고정 |
| 몸통 | 흰색 | 스피커 그릴 구멍, SNW-01 각인, 고개 좌우 서보 자리 |
| 바닥판 | 밝은 회색 | USB-C 구멍, 무게판·고무발 자리 |

색은 흰색 기준이다. 짙은 회색·얼음 파랑 안과 반투명 뒤 덮개는 아직 정하지 않았다. 본 출력 전에 정하면 된다.

## 4. 시험 출력에 넣을 것 (본 출력 전에 한 번)

1. **공차 시험 조각** — 작은 판 하나에 크기를 조금씩 바꾼 구멍을 나란히 뚫는다. 받아서 어느 것이 꼭 맞는지 고른다.
   - 인서트 구멍 지름 3.0 / 3.1 / 3.2mm
   - 서보 끼우는 홈: 실측 + 0.2 / 0.3 / 0.4mm
   - 베어링 자리 지름 19.0 / 19.1 / 19.2mm
   - M2 나사 구멍 2.2 / 2.4mm
2. **눈 기구만 따로** — 얼굴판 일부 + 눈 2개 + 눈꺼풀 + 눈썹 + 서보 자리. 가장 어려운 부분이라 먼저 움직여 본다.
   카메라 렌즈가 검은자 가운데에 오는지, 코가 카메라 화면에 비치는지도 여기서 본다.
3. **목 관절** — 회전판 + 베어링 + 서보 혼. 머리 무게를 받고 흔들리지 않는지 본다.

## 5. 설계 규칙 (출력 대행 PLA 기준, 시작값)

- 바깥 껍데기 벽 두께 2mm 이상. 나사·인서트 주변은 3mm 이상.
- 맞물리는 조각 사이 틈 0.2~0.3mm (시험 조각 결과로 고친다).
- 인서트 구멍 깊이는 인서트 길이(3mm)보다 0.5~1mm 깊게.
- 받침 없이 떠 있는 면은 45도보다 눕히지 않는다. 안 되면 조각을 나눠 출력 방향을 바꾼다.
- 겉으로 보이는 면(얼굴판 앞)은 지지대가 닿지 않게 출력 방향을 정한다.
- 열 빠질 길: 보드 뒤 환기 슬롯. 카메라가 OV3660 으로 올 예정이라 OV5640 보다 열 걱정이 적지만 구멍은 둔다.
